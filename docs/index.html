How do I get the video out of Instagram or YouTube?

This page converts a file you already have — it can't fetch from a link, because browsers block one site from reading another's content. Save the clip first (Instagram: ⋯ → Download; many apps have a Save or Share-to-Files option), then drop that file here.

If you'd rather paste links directly, the companion tool does that, but it has to run on your own machine — grab it here.

Powered by ffmpeg.wasm. First use downloads a ~31 MB engine, then it's cached. Source. Please only convert media you have the right to use.
